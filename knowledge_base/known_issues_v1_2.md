# Known Issues - Virtual Bank App v1.2

**Overview:**
Version 1.2 of the Virtual Bank App introduced several usability improvements and backend refactors, but also a few known issues.

**Known Issues:**

1.  OTP verification may fail intermittently for corporate customers using Digital Lending.
2.  Some Android 14 users experience app crash on login due to library conflict.
3.  Slow dashboard loading when Digital Savings accounts exceed 20 sub-accounts.
4.  Incorrect loan interest display in rare cases (fix planned for patch 1.2.1).

**Fixes in Progress:**

- Patch 1.2.1: fixing OTP delay and crash issues.
- Patch 1.2.2: performance optimization for dashboard loading.
